Trino + PostgreSQL + MinIO Lakehouse

Set up a local data lakehouse using Trino, PostgreSQL, MinIO, and Hive Metastore. Seeded normalized datasets with Faker and pyarrow, exported them to Parquet-backed Iceberg tables on MinIO (S3-compatible), and queried across sources via Trino. The whole stack runs in Docker Compose so it's reproducible on any machine.
